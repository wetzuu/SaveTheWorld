01 / About

Early in the story, honest about it.

I started programming in 2018 with a small JavaScript Discord bot, following my curiosity and learning as I went. That bot is still one of my oldest public repos, and was one of the reasons I ended up pursuing Computer Science.

Now in my second year at Mapúa University, I turn personal interests and course projects into apps people can use. Though I work mainly with React and TypeScript, I'm currently learning Node.js, Express, Prisma, and database design by building beyond the front end.

I'm find myself still a bit early in my career. That's why I try to learn by deploying, revisiting old decisions, and improving projects as my understanding grows. Outside the code, I help organize organization events and connect with other devs. Sweet coffee and dogs are always welcome.

02 / Work

Selected projects.

Seven projects spanning web apps, desktop experiments, and my first Discord bot. A mix of ongoing work, deployed apps, and learning projects.

01

SafeGo↗

2026 · active development

A travel-risk information app for severe weather in Metro Manila, Philippines. Enter an origin and destination to explore a real road route, color-coded risk sections, modeled weather, and the sources behind each assessment.

Grown from a static prototype into a Next.js app with OSRM routing, Open-Meteo weather, and optional PostgreSQL/PostGIS storage. Still a development pilot: coverage is limited, official feeds need configuration, and community submissions remain disabled pending moderation.

  • TypeScript
  • Next.js
  • React
  • PostgreSQL
  • PostGIS
  • OSRM

Penumbra↗

2026 · early development

An offline math notebook that recognizes handwritten expressions, solves them locally, and writes answers back in the user's handwriting. Developed for the 2026 Cintana Alliance AI Challenge.

A collaborative project hosted by aeyvmor. The Windows app is in early development, exploring pen input, handwriting recognition, and computer algebra without a cloud account.

  • C#

03

Semita↗

2026 · live on Vercel

A private, browser-based personal finance tracker. Record income and expenses, manage categories and payment methods, set monthly budgets, review reports, and export your data when needed. All data stays in the browser; Semita does not require an account or server.

Built around everyday student budgeting: recurring transactions, quick-add shortcuts, and spending trends. Zustand keeps state in local browser storage, with JSON export and import for backups.

  • TypeScript
  • React
  • Vite
  • Zustand
  • React Router
  • Recharts
  • Framer Motion
  • date-fns

04

Bahay ni Kuya↗

2026 · course project

An app for a boarding-house management system: tenants, rooms, leases, payments, maintenance requests, and reports; plus an ER-diagram viewer and database backup pages for the admin side.

A full-stack project connecting a reusable React dashboard to an Express API, Prisma, and PostgreSQL. Working across the interface, data model, and local setup has been a practical introduction to backend development.

  • TypeScript

05

une odeur v2↗

2026 · live on Vercel

A fragrance discovery and review site for local and, perhaps, obscure brands. Browse perfumes by category, read community reviews, and keep an account of your favorites. Built with React and Supabase for auth and data.

The interesting part: this is a full rewrite. v1 was built in Astro, and rebuilding it in React with a real backend meant rethinking routing, state, and data fetching from scratch.

  • React
  • Supabase
  • Vite
  • Tailwind CSS

06

HomeQuest↗

2026 · course project

A desktop real-estate management app in Java Swing with three distinct roles: owners list properties, agents process transactions, buyers browse listings; each with its own workspace.

The role-based design was the point: separate models and workspaces per user type, built to practice inheritance and encapsulation on something bigger than a textbook exercise.

  • Swing
  • NetBeans
