# Matthew's portfolio

A static portfolio built with HTML, CSS, and dependency-free JavaScript. The terminal dog and green editorial styling are part of the existing visual identity.

## Preview and checks

Serve this directory with any static HTTP server, then open `index.html`. No build or package installation is required. Run `npm run check` to check the JavaScript syntax.
